# ATS CV Tailor - Chrome Extension

## How to Install in Google Chrome
1. Open Google Chrome and navigate to `chrome://extensions/`.
2. Toggle on **Developer mode** in the top right corner.
3. Click the **Load unpacked** button.
4. Select this directory (`c:\Users\Utente\Desktop\Linkedin\extension`).

## How to Use
1. Go to any job listing on LinkedIn (e.g. `https://www.linkedin.com/jobs/view/...`).
2. Click on the **ATS CV Tailor** extension icon in your Chrome toolbar.
3. The extension extracts the job title, company, and full job description text.
4. It immediately opens your local web application (`http://localhost:5173`) and automatically injects the extracted Job Description into the `#jd-input` textarea!
